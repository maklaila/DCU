# Práctica DCU - Bachillerato's Mind

Instrucciones para instalar y ejecutar el proyecto localmente.

## Requisitos previos
Tener instalado **Node.js** y **npm** en el equipo.

## Pasos para la instalación

1. Descomprimir el archivo ZIP.
2. Abrir una terminal dentro de la carpeta del proyecto (asegurarse de estar en la ruta donde se encuentra el archivo `package.json`).
3. Instalar las dependencias con el comando:

```bash
npm install
